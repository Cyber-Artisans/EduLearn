# 🎓 EduLearn

### Learn Skills. Build Your Future.

**EduLearn** is a modern and responsive e-learning platform designed to provide students with a clean, engaging, and intuitive environment for exploring educational content.

The project focuses on creating a polished learning experience through a structured interface, responsive layouts, reusable React components, and modern frontend technologies.

🌐 **Live Demo:** https://edu-learn-virid.vercel.app/

---

## ✨ Features

* 🎓 **Modern E-Learning Interface**
  A clean and engaging interface designed around the online learning experience.

* 📚 **Learning-Focused Sections**
  Structured content and sections that make it easier for users to discover and explore educational resources.

* 📱 **Fully Responsive Design**
  Designed to provide a consistent experience across desktop, tablet, and mobile devices.

* 🍔 **Responsive Navigation**
  Includes a mobile-friendly navigation experience with a dedicated mobile menu.

* 🧩 **Reusable Components**
  Built using reusable React components to keep the application organized and maintainable.

* 🎨 **Modern UI Design**
  Uses Tailwind CSS and DaisyUI to create a clean, modern, and consistent visual experience.

* 🧭 **Client-Side Routing**
  Uses React Router for navigation between different parts of the application.

* ⚡ **Fast Development Experience**
  Powered by Vite for fast development and efficient production builds.

# 🚀 Getting Started

Follow the steps below to run EduLearn locally.

## 1. Clone the Repository

```bash
git clone https://github.com/Cyber-Artisans/EduLearn.git
```

## 2. Navigate to the Project

```bash
cd EduLearn
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start the Development Server

```bash
npm run dev
```

Vite will start the development server and provide a local URL where you can access the application.

# 📱 Responsive Design

EduLearn was designed with responsiveness as an important part of the user experience.

The interface adapts to different screen sizes, providing a usable experience across:
